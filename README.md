# Alvin and Arden: The Shards of Destiny

A 2D pixel action-adventure RPG built with **Godot Engine 4**. Designed to run smoothly on any modern laptop without requiring dedicated GPU hardware.

---

## 🎮 Overview

*Alvin and Arden: The Shards of Destiny* takes players through dynamic, retro-styled environments filled with enemies, dungeons, and interactive NPCs. While featuring a rich story with a definite beginning and end, unique journeys through diverse memories ensure that no two playthroughs are ever the same.

---

## ✨ Features

- **Responsive Player Controller & State Machine**:
  - Walk, Dash, Idle, Stun, Death
  - Melee Attacks & Spin / Charge Attack
  - Ranged Bow & Boomerang abilities
  - Object lifting, carrying, and throwing
  - Grappling mechanics
- **Interactive NPC & Quest System**:
  - Modular NPC behaviors (Patrol, Wander, Dialogue, Quest-giver)
  - Global quest management and objective tracking triggers
  - Portrait dialogue system
- **Dungeon & Overworld Design**:
  - Custom tilemaps with atmospheric dynamic torch lighting and shaders
  - Destructible environment props (pots, plants, switches)
  - Custom audio effects and retro background soundtracks
- **Lightweight & Optimized**:
  - Runs natively on integrated graphics without GPU upgrades.

---

## 🛠️ Built With

- **Engine**: [Godot Engine 4](https://godotengine.org/)
- **Language**: GDScript
- **Art & Sound**: Custom 2D Pixel Art Sprites, Tilemaps, and Retro Audio FX

## 🚀 Getting Started

### Prerequisites

- [Godot Engine 4.x](https://godotengine.org/download) (Standard Edition)

### Running in the Editor

1. Clone or download this repository:
   `ash
   git clone https://github.com/Bajazz0703/Alvin-and-Arden-The-Shards-of-Destiny.git
   `
2. Open **Godot Engine**.
3. Click **Import** and select the project.godot file in this directory.
4. Click **Import & Edit**.
5. Press F5 (or click the **Play** button at the top right) to launch the game.
